# FinanSmart - Seu Controle Financeiro Moderno

Um aplicativo premium de controle financeiro pessoal com Modo Dark, gráficos interativos e sistema de login.

## 🚀 Funcionalidades
- **Dashboard Premium**: Visão geral de saldo, entradas e saídas.
- **Gráficos Interativos**: Evolução diária e gastos por categoria usando Chart.js.
- **Modo Dark**: Interface adaptável para maior conforto visual.
- **Persistência Real**: Integrado com Supabase (em breve).
- **GitHub Pages**: Acesso rápido via web.

## 🛠️ Tecnologias
- HTML5 / CSS3 (Vanilla)
- JavaScript (Vanilla)
- [Lucide Icons](https://lucide.dev/)
- [Chart.js](https://www.chartjs.org/)
- [Supabase](https://supabase.com/)

## 📦 Como rodar este projeto
1. Clone o repositório.
2. Abra o arquivo `index.html` em seu navegador.
